# anvynt — sitio corporativo

Next.js 14 (export estático) + Tailwind. Textos en `src/i18n` (es / en).

```bash
cp .env.example .env.local   # completar número de WhatsApp y dominio
npm install
npm run dev                  # desarrollo
npm run build                # genera out/
npx serve out                # previsualizar el build
```

Detalles de arquitectura y reglas del proyecto: [CLAUDE.md](CLAUDE.md).
